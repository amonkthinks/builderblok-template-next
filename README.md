# BuilderBlok site

This repository was created by BuilderBlok.

- `builderblok/` holds the site as JSON (config and pages). The builder commits here, so edit these files through BuilderBlok.
- `app/` and `lib/` are a Next.js app that renders them (`lib/render.tsx`), exported as a static site to `out/`.

```bash
npm install
npm run dev
```
